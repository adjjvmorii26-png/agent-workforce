# Reuse — reviving dormant organisms

This folder is the hub's **reuse engine**. It catalogs dormant projects found on
this machine and defines how the simulation re-animates ("mutates back to life")
and reuses them.

- `INVENTORY.md` — every discovered project, its status, and a reuse plan.
- `reuse-scan` recipe (`ixpansion/content_output/recipes/reuse-scan.yaml`) — given a
  path, produces a revival + reuse plan for that organism.

Principle: nothing is wasted. Every dormant repo becomes an agent input, a recipe
seed, a reference, or a revived node synchronized back into the hub.
